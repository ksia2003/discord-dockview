# DockView Markdown Sample

A short document exercising the **Markdown** renderer: headings, lists, a code
block, a table, and inline styles.

## Features

- Live GitHub-flavoured rendering
- Syntax-highlighted code fences
- Tables with alignment

## Code

```ts
export function greet(name: string): string {
    return `Hello, ${name}!`;
}
```
